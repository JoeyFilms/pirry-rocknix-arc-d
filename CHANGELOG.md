# Changelog

## v1.1.0-beta.1 — Pirry 1.6.3

- Pin and verify the upstream ARM64 executable from the `v1.6.3_dArkOS` release.
- Update the installer ZIP for new installs and upgrades from 1.6.2.
- Retain the ROCKNIX 20261001 and 20261101 firmware targets for RG ARC-D.
- Gameplay on the handheld is pending for 1.6.3.

## v1.0.0-beta.1 — first prepared public integration release

- Combine the Pirry 1.6.2 installer, Saturn menu integration and controller repair into one install action.
- Target official ROCKNIX 20261001 and 20261101 on RG ARC-D.
- Use the correct six-button ARC mapping for either raw controls or InputPlumber's virtual DualSense interface.
- Preserve existing saves/custom same-interface controls and back up replaced components.
- Verify the downloaded upstream executable and copied helpers.
- Retain normal Saturn game entries/artwork and stock emulator choices.
- Provide a single visible installation log and an optional disable action.
- Include detailed setup, troubleshooting and GitHub publishing documentation.

This is the integration package's version. It installs upstream Pirry **1.6.2** and does not automatically track newer upstream releases.
