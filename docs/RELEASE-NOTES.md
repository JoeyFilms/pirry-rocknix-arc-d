## Pirry Complete for RG ARC-D — Pirry 1.6.3 beta

One installer for the original Pirry 1.6.3 emulator, ARC controls and a native Saturn emulator choice on ROCKNIX.

### Targets

- Anbernic **RG ARC-D**.
- Official ROCKNIX **20261101** (main documented setup) or **20261001**.
- Original upstream **Pirry v1.6.3**, downloaded from its author and checksum-verified.

### Install

Download **Pirry-Complete-1.6.3-ARC-D.zip** from the project README. Extract into the games card's `ports` folder, connect to Wi-Fi, refresh game lists, and run **Install-Saturn-Pirry**. Restart ROCKNIX, then choose **pirry** in Saturn's system emulator settings.

The complete package includes the InputPlumber controller fix and normal Saturn menu integration. No older separate packages or per-game Ports shortcuts are required.

### Notes

Saves and existing artwork are retained. The installer pins 1.6.3 rather than automatically fetching future upstream releases. No games, BIOS, artwork or emulator executable are bundled.

Pirry 1.6.2 and the updated controller helper worked on the ARC-D. Gameplay testing on the ARC-D is pending for 1.6.3.
